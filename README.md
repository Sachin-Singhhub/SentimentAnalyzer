
# Sentiment Analyzer

## Project Description
This project analyzes a text review and classifies it as Positive, Negative, or Neutral.

## Technologies Used
- Python
- VS Code

## Features
- Accepts a review from the user.
- Identifies basic positive and negative keywords.
- Displays the sentiment result.

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run: `python3 main.py`
4. Enter a review and check the result.

## Current Version
Basic rule-based sentiment analysis.
